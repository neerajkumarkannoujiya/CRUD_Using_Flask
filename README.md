# 🔧 Flask CRUD Web Application

A simple and beginner-friendly **CRUD (Create, Read, Update, Delete) web application built using Flask and SQLite**.

This project demonstrates how to build a database-driven web application with Flask, SQLAlchemy, Jinja2 templates, HTML, CSS, and Bootstrap.

---

## 📌 About the Project

CRUD stands for:

- **Create** — Add new records
- **Read** — View existing records
- **Update** — Modify existing records
- **Delete** — Remove records

This application provides a simple interface to perform all four operations on data stored in a SQLite database.

The project is designed to help understand the fundamentals of **Flask routing, forms, database operations, SQLAlchemy ORM, and template rendering**.

---

## ✨ Features

- ➕ Create new records
- 👁️ View all records
- ✏️ Update existing records
- 🗑️ Delete records
- 🗄️ SQLite database integration
- 🔗 SQLAlchemy ORM
- 🎨 Bootstrap-based UI
- 📄 Jinja2 templates
- 🔄 Dynamic data rendering
- 📱 Responsive interface
